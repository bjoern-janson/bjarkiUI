# 0.2.357 timer handoff recovery

## Evidence and scope

The user's `.356` `/buitimers` capture reports zero active action cell presenters, two stock fallbacks whose reasons were lost (`unavailable`), and no minimum-duration refusals. All 48 ordinary aura hooks are installed; readable decimal writes have occurred, while the latest native-duration fallback is `aura ID secret`. Four glyph profiles are naturally tabular, but their optional full formatters incorrectly report a layout failure.

Two defects reproduce against unchanged `.356` source: a first failed action visibility handoff does not retain the fallback needed for the next native cooldown update to retry; and pixel-rounded width measurements unnecessarily reject an unchanged formatter for a naturally tabular font. The screenshot does not establish why the native visibility handoff failed, nor that every buff has a secret identity.

## Implementation

1. Add a focused action regression for a first refused stock-hide write followed by an ordinary native cooldown update, plus accepted-write/readback refusal and external-writer ownership cases. Observe native visibility, rendered bindings, resource reuse and the diagnostic reason. Preserve the existing safe preparation, native clock, minimum-duration and reentrancy rules.
2. Retain a named stock fallback when our own visibility handoff is refused, so existing native updates can retry. Record fixed public stage names for the failed write/readback and restoration; never print error payloads or inspect hidden timing.
3. Add naturally tabular, pixel-rounded native-font cases for the full action and suffix formatters. Return the exact native formatter after successful natural glyph preparation; skip unnecessary transformed-string validation for this identity operation.
4. Verify the supported native alternatives for secret-ID ordinary buffs. Preserve current native rows and formatting unless an explicit supported in-place API exists. Document any remaining native limitation rather than inventing an identity or clock.
